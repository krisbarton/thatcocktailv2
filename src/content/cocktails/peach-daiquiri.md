  - { item: lime juice, ml: 15, oz: 0.5 }

  - 'Add ice, <a href="/alcohol-recommendations/#rum">white rum</a>, <a href="/alcohol-recommendations/#peach-schnapps">peach schnapps</a>, and lime juice into a <a href="/cocktail-equipment/#cocktail-shaker">cocktail shaker</a>.'

  - Garnish with a wedge of peach.
